# 人设与记忆

## 人设文件

`data/persona.md` —— 整段提示词，直接粘贴即可，**只对微信桥生效**，不影响 App 里聊天的助手。

- 没有这个文件时，用 `config.json` 的 `persona.name` + 内置默认人设
- 改完在「AI 管理」点「重载人设」，不用重启
- 占位符（可省略）：

| 占位符 | 替换成 |
|---|---|
| `{{name}}` | `config.json` 的 `persona.name` |
| `{{who}}` | 对方昵称/备注 |
| `{{where}}` | `私聊` 或 `群聊「群名」` |
| `{{summary}}` | 会话摘要（暂无内容时为空） |
| `{{memory}}` | 长期记忆（≤1200 字） |

插件会在末尾自动追加三条硬规则，不用自己写：

```
（当前场景：你正在和<who><where>聊天。）
只输出要发出去的那句话，不要加引号、前缀或任何说明。
每次只说一两句，一句不超过 20 个字；不要用列表、破折号、分隔线或 Markdown。
对方只发了 [表情]/[图片]/[语音] 这种占位时，自然接一句就好，别去描述内容。
```

## 记忆库

每个联系人一份：`data/memory/<wxid>.md`，纯文本，重启不丢。

| 环节 | 做法 |
|---|---|
| 注入 | 每次回复前把记忆（≤1200 字）塞进系统提示词 |
| 自动更新 | 每 5 条对话跑一次「记忆整理」：读旧记忆 + 最近 16 句，只留稳定事实 |
| 手动 | 「AI 管理」→ 整理记忆 / 清空记忆（需从对话详情页打开，绑定当前会话） |

整理用的提示词要求：只保留称呼、喜好、习惯、在忙的事、约定；不记寒暄、不复述原话、最多 15 行，用第三人称短句。

整理在后台跑，失败只记日志，不影响正在回复的那条。

## 分段与节奏

- 一个话题只发一条；模型用换行决定发几条，提示词禁止为凑段拆句
- 单段超过 45 字才在逗号处断；很长的段落隔一个逗号换空格，像手打字
- 段数超过 6 才合并，并进最后一段，不丢字
- 整句不超过上限就一条发完，不会被硬切
- 切分优先在 `。！？…\n` 之后，其次在逗号类软断点；`-` `*` `·` 等列表符号剥掉；≤2 字碎段并进上一段
- 延迟 = 区间随机 + 字数加权，最多再加 2500ms

## 换模型的影响

| 方面 | 影响 |
|---|---|
| 人设遵循 | 弱模型容易客服腔、爱解释，硬规则可能不遵守 |
| 口语感 | 有的模型中文偏书面 |
| 速度成本 | 延迟和计费不同 |
| 上下文 | 记忆 + 历史都塞进提示词，窗口小的模型会截断 |

分段、断句、延迟由插件控制，**和模型无关**。换模型在「模型与记忆」里选，会先探测再保存；`provider`/`model` 与 App 里选的模型互不影响。识图是另一套模型，两者独立。
