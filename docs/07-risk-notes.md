# 风险与注意事项

## 账号风险

- Hook 微信属于非官方行为，存在被检测、限制或封号的可能
- 建议先用小号验证，再上主号
- 别群发、别高频、别在群里刷屏：`rateLimitPerMinute` 和 `segments.max` 就是为此设的
- 涉及转账、支付、验证码的对话不要交给 bot

## 隐私

- **聊天内容会发到云端模型**：收到什么、人设和记忆都会进提示词
- 记忆和人设明文存在 `data/` 里，手机上任何能读 proot 文件系统的东西都能看到
- 不主动索要密码、验证码、API Key；提示词里也写了这条
- 想停就停：面板「暂停」，或把白名单清空

## 技术风险

| 风险 | 影响 | 缓解 |
|---|---|---|
| 微信升级改混淆名 | 收发失效 | 锁版本；升级后按 04 重找 `y11.s1` / `e01.e2` |
| 模块导致微信崩溃 | 聊天受影响 | 全部 hook 包 try-catch，异常只记日志 |
| 引擎重启期间丢消息 | 那几十秒的消息不回 | 已知行为，不做补发 |
| 模型报错 | 这条不回 | 日志 `model failed`，面板换模型会先探测 |
| 端口暴露 | 本机其它程序可调用 | 只监听 `127.0.0.1`；需要时在 `config.json` 设 `token` |

## 环境风险

- Root 会失去保修，LSPosed 可能影响系统稳定性
- 改微信数据前先备份；本方案只读取数据库、不写数据库，风险主要在发送链路

## 更新策略

- 关掉微信自动更新，保留当前版本 APK（`/sdcard/Download/DSHGO/微信_8.0.76.apk`）
- 升级微信前先确认模块能重新定位锚点
